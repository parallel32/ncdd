
Member
can create new forums, which puts their name as the author of the forum.  They moderate topics.
can comment on any topic

Admin 
can delete any comment, topic, or forum as well as edit
can create a new forum, which will not have the author of the forum labeled

Forum
has an owner
anyone can post
if admin -> admin is emailed
if member -> owner is emailed when someone posts


Topics
has an author; only author, forum owner, or Admin can edit / delete a topic
If forum has an owner only the owner can post topics
Anyone can post a topic to a forum owned by admin

Comment
has an author; only author, forum owner, or Admin can edit / delete a comment
can create new comment or reply to existing comment.  
Reply does not create a new thread, instead just posts there 

Email
A weekly abridged email will go to the listserv 
forum owner is emailed (if not admin) when someone comments
Admin is emailed when someone posts to a forum owned by admin
member is emailed when someone replys to their comment.  They have the option to be emailed and then turn off their emails on the thread later
